KB국민카드 KB Pay 3.0 구축

프로젝트 개요

KB Pay 3.0 프로젝트에서 개인화 서비스를 강화한 홈 탭, 고객 혜택을 한곳에 모은 혜택 탭, 금융 서비스를 집중 배치한 금융 탭 중심으로 메인 인터페이스 구조를 전면 재구성하고 대출 신청, 카드 신청 프로세스, 포인트, 이용내역을 모바일 웹과 앱 환경의 접근성을 고려하여 개편하는 UI 퍼블리싱 작업을 진행하였습니다.

나의 역할

UI 퍼블리싱 리드로 참여해 메인 UI 작업과 공통 마크업·스타일 구조 설계를 담당했습니다. 메인 홈·간편 홈·포인트 영역의 화면 개편과 주요 인터랙션 구현을 수행했습니다.

문제 / 요구사항

KB Pay 3.0 구축 범위에 포함되지 않는 카테고리의 마크업 및 스타일 가이드는 유지하면서 신규 개편되는 핵심 탭의 공통 스타일을 개선해야 했습니다. 개편된 메인 홈·금융·혜택 탭과 대출 신청·카드 신청 프로세스 등 개편되는 화면과 기존 화면이 함께 사용되는 만큼 디자인 일관성과 서비스 이용 흐름을 고려해야 했습니다.

구현

주요 탭 UI 개편

메인 홈·간편 홈 영역을 개편된 디자인에 맞춰 구현했습니다. 개인화 영역 패턴을 도입하고 메인 화면의 반복 UI를 공통 구조로 정리했습니다.

공통 마크업·스타일 정리

기존 마크업과 스타일을 유지하면서 공통 스타일 구조를 개선했습니다. 주요 탭 사이에서 화면 구성과 디자인 표현이 일관되도록 작업했습니다.

접근성과 인터랙션

모바일 웹과 앱 환경의 접근성을 고려해 UI를 구현하고 개편된 화면에 필요한 인터랙션을 작업했습니다.

결과

  • 홈·금융·혜택 등 주요 탭 UI 개편
  • 메인 화면 공통 UI와 개인화 영역 패턴 적용
  • 공통 마크업·스타일 구조 정리
  • 모바일 웹·앱 접근성을 고려한 UI 구현
  • 개편 화면의 주요 인터랙션 구현

사용 기술

JavaScriptHTMLCSS

경험

개편되는 화면에서도 기존 구조를 유지해야 하는 부분이 있었습니다. 공통 UI를 정리할 때 신규 화면의 디자인뿐 아니라 기존 화면에 적용되는 범위까지 살펴보는 것이 중요했습니다.
