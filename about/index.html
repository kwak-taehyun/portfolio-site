About

소개

UI를 이해하는 것에서 시작해, 프런트엔드 개발까지

10년 이상 웹 퍼블리셔로 근무하며 금융, 모빌리티, 커머스, 교육 등 다양한 서비스 환경에서 공통 UI 가이드 설정 및 UI 구현, 인터렉션 구현 업무를 수행하여 왔으며, 구축·고도화·서비스 운영 등의 다양한 프로젝트를 경험했습니다. 디자인을 화면에 그대로 옮기는 것보다 실제 사용 환경을 고려하고 유지보수하기 쉬운 구조로 작업하는 것을 중요하게 생각하고, 단순한 화면 구현을 넘어 최근에는 React와 Typescript 기반 프로젝트에서 UI 컴포넌트 구현과 기능 개선을 경험하며 프런트엔드 영역으로 업무 범위를 넓혀가고 있습니다. 그동안의 퍼블리싱 경험을 기반으로 컴포넌트의 역할과 재상용 범위를 고민하고, 상태와 데이터 흐름을 이해하며 화면을 구현하는데 집중하고 있습니다. 아직 경험하지 못한 영역에 대해서도 단순히 코드를 작성하는 것보다 기존 구조를 먼저 이해하고, 왜 이렇게 구현되어야 하는지를 파악하고 안정적으로 개선하는 방식을 중요하게 생각합니다.

작업 철학

  • 사용자를 고려한 인터페이스 구현.
  • 유지보수를 고려한 코드와 주석처리.
  • 서로 존중하며 더 나은 결과를 위한 소통과 협업.

전문분야

  • Semantic HTML

    화면의 모양만 맞추는 마크업보다 콘텐츠의 의미와 문서 구조를 고려한 마크업을 중요하게 생각합니다. 서비스 규모가 커져도 구조를 이해하기 쉽고 유지보수하기 좋은 HTML을 작성하는 것을 기본 원칙으로 삼고 있습니다.

  • CSS & Responsive UI

    다양한 해상도와 디바이스 환경을 고려한 반응형 UI를 구현해왔습니다. 디자인을 그대로 재현하는 데 그치지 않고 공통 스타일과 반복되는 UI 패턴을 정리해 수정과 확장이 쉬운 구조를 만드는 데 중점을 두고 있습니다.

  • Web Accessibility

    금융·커머스 등 다양한 프로젝트에서 웹 접근성을 고려한 UI를 구현했습니다. 시맨틱 요소와 키보드 접근, 포커스 이동, 대체 텍스트와 ARIA 속성 등을 실제 서비스 환경에서 고려하며 작업해왔습니다.

  • UI Development

    기획과 디자인 의도를 이해하고 이를 실제 서비스에서 안정적으로 동작하는 UI로 구현하는 것이 가장 큰 강점입니다. 디자이너와 개발자 사이에서 구현 가능성을 검토하고, 개발 과정에서 발생할 수 있는 UI 이슈를 미리 발견해 조율하는 역할도 꾸준히 수행해왔습니다.

협업 경험

디자이너와 화면 및 컴포넌트 스펙을 확인하고, 프런트엔드·백엔드 개발자와 구현 방식과 데이터에 따른 UI 상태를 협의하며 작업해왔습니다. QA 과정에서는 재현 조건과 화면 상태를 정리해 이슈를 공유하고 수정 결과를 확인하는 방식으로 협업해 왔으며, Photoshop · Figma · Zeplin · Git · Slack · Jira · Confluence 등 다양한 도구를 활용해왔습니다.

AI 활용

AI를 코드 생성 도구보다 기존 코드 분석과 구현 방법을 검토하는 보조 도구로 활용하며, 생성한 코드를 그대로 적용하기보다 현재 프로젝트 구조와 요구사항에 맞는지 확인하고 수정하는 과정을 거치고 있습니다.

  • 기존 코드 구조 및 컴포넌트 의존 관계 분석
  • 구현 방법 비교 및 초안 작성
  • 반복되는 마크업 작성 보조
  • 오류 원인 탐색 및 수정 방향 검토
  • 작성된 코드의 프로젝트 구조 적합성 재검토
  • 브라우저에서 직접 동작 확인 후 코드 수정
