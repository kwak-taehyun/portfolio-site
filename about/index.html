About

소개

UI를 이해하는 것에서 시작해, 프런트엔드 개발까지

10년 이상 웹 퍼블리셔로 일하며 금융, 모빌리티, 커머스, 교육 등 다양한 서비스의 UI를 구현하고 에이전시·SI·서비스 운영 등 다양한 환경에서 마크업과 UI 구현, 공통 UI 가이드 및 컴포넌트 작업을 경험했습니다. 디자인을 화면에 그대로 옮기는 것보다 실제 사용 환경을 고려하고 유지보수하기 쉬운 구조로 작업하는 것을 중요하게 생각합니다. 단순한 화면 구현을 넘어 데이터와 상태에 따라 움직이는 하나의 기능이라는 점에 관심을 갖게 되었고, React와 Vue 기반 프로젝트에 참여하며 프런트엔드 개발 영역으로 업무 범위를 넓혀왔습니다. 현재는 React와 TypeScript를 중심으로 컴포넌트 설계와 상태 관리, 데이터 흐름을 학습하고 실제 프로젝트에 적용하면서 부족한 부분을 채워가고 있습니다. 오랜 퍼블리싱 경험에서 쌓은 UI 구현 능력과 웹 표준·접근성에 대한 이해를 기반으로, 사용하기 편하고 유지보수하기 좋은 프런트엔드를 만드는 개발자로 성장하는 것이 목표입니다.

전문 분야

  • Semantic HTML

    화면의 모양만 맞추는 마크업보다 콘텐츠의 의미와 문서 구조를 고려한 마크업을 중요하게 생각합니다. 서비스 규모가 커져도 구조를 이해하기 쉽고 유지보수하기 좋은 HTML을 작성하는 것을 기본 원칙으로 삼고 있습니다.

  • CSS & Responsive UI

    다양한 해상도와 디바이스 환경을 고려한 반응형 UI를 구현해왔습니다. 디자인을 그대로 재현하는 데 그치지 않고 공통 스타일과 반복되는 UI 패턴을 정리해 수정과 확장이 쉬운 구조를 만드는 데 익숙합니다.

  • Web Accessibility

    금융·커머스 등 다양한 프로젝트에서 웹 접근성을 고려한 UI를 구현했습니다. 시맨틱 요소와 키보드 접근, 포커스 이동, 대체 텍스트와 ARIA 속성 등을 실제 서비스 환경에서 고려하며 작업해왔습니다.

  • UI Development

    기획과 디자인 의도를 이해하고 이를 실제 서비스에서 안정적으로 동작하는 UI로 구현하는 것이 가장 큰 강점입니다. 디자이너와 개발자 사이에서 구현 가능성을 검토하고, 개발 과정에서 발생할 수 있는 UI 이슈를 미리 발견해 조율하는 역할도 꾸준히 수행해왔습니다.

작업 철학

  • 사용자를 고려한 인터페이스 구현이 먼저입니다.
  • 유지보수를 고려한 코드와 다음 사람을 위한 주석과 구조를 남깁니다.
  • 서로 존중하며 더 나은 결과를 위해 협력합니다.

협업 경험

디자이너와 화면 및 컴포넌트 스펙을 확인하고, 프런트엔드·백엔드 개발자와 구현 방식과 데이터에 따른 UI 상태를 협의하며 작업해왔습니다. QA 과정에서는 재현 조건과 화면 상태를 정리해 이슈를 공유하고 수정 결과를 확인하는 방식으로 협업해 왔으며, Figma · Git · Slack · Jira · Confluence · Zeplin 등 다양한 도구를 활용해왔습니다.
