SK렌터카 B2C 통합운영

프로젝트 개요

SK렌터카 회사 소개 사이트, 중고차 판매, 렌터카 예약 사이트 운영하였으며 렌터카 예약 사이트에 코레일 제휴 기능을 개선하여 코레일 앱에서 렌터카 조회와 예약을 할 수 있는 웹뷰 기반 UI 퍼블리싱을 담당했습니다.

나의 역할

렌터카 예약, 중고차 판매, 회사 소개 사이트의 UI 운영과 개선을 담당했으며, 코레일 제휴 전용 웹뷰의 퍼블리싱에도 참여했습니다.

문제 / 요구사항

사이트마다 사용 기술과 기존 구조가 달라 각각의 환경에 맞는 UI 작업이 필요했습니다. 코레일 제휴 화면은 앱 안의 웹뷰 환경에서 렌터카 조회·예약 흐름을 제공해야 했습니다.

구현

여러 사이트 UI 운영

React, Vue 등 서로 다른 환경의 렌터카 예약·중고차 판매·회사 소개 사이트에서 UI 운영과 개선을 진행했습니다.

코레일 제휴 웹뷰

코레일 앱에서 이용하는 제휴 전용 렌터카 웹뷰의 UI 퍼블리싱을 수행했습니다. 조회·예약 기능을 제공하는 프로젝트에서 화면 구현을 담당했습니다.

기존 기능의 UI 개선

차량 예약 부가상품과 중고차 차량진단 서비스 등 기존 기능의 UI 개선 작업을 진행했습니다.

결과

  • 렌터카 예약·중고차 판매·회사 소개 사이트 UI 운영 및 유지보수
  • 코레일 제휴 렌터카 조회·예약 웹뷰 UI 구현
  • 차량 예약 부가상품과 중고차 차량진단 서비스 UI 개선

사용 기술

Reactstyled-componentsVueHTML

경험

여러 서비스를 함께 운영할 때는 같은 UI 작업이라도 프로젝트별 구현 환경에 맞게 접근해야 했습니다. 새로운 화면을 추가하는 능력과 기존 코드의 맥락을 파악하는 능력이 모두 필요한 경험이었습니다.
