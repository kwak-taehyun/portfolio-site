NH농협 태블릿브랜치 고도화

프로젝트 개요

NH농협 태블릿브랜치, 스마트워크, 스마트워크 관리자 화면의 고도화 프로젝트에 참여했습니다. 대출 프로세스 개선을 통한 UI 개선과 태블릿 기종별 화면 대응을 담당했습니다.

나의 역할

UI 퍼블리싱을 전담해 태블릿 화면 대응, 기존 UI 오류 수정, 대출 프로세스와 관리자 화면 개선을 수행했습니다.

문제 / 요구사항

지점별로 보유한 태블릿 기종과 화면 크기가 달라 UI 대응이 필요했습니다. 지원 운영체제 환경을 고려하면서 기존 화면 오류도 수정해야 했습니다.

구현

태블릿 화면 대응

기종과 화면 크기에 맞춰 미디어쿼리와 유동적인 레이아웃을 적용했습니다.

업무 화면 개선

대출 프로세스와 스마트워크, 관리자 기능 변경에 필요한 UI를 작업했습니다.

기존 UI 오류 수정

기존 화면의 UI 오류를 수정하고 지원 환경에 맞춰 화면을 개선했습니다.

결과

  • 태블릿 기종과 화면 크기에 따른 UI 대응
  • 대출 프로세스·스마트워크 화면 UI 개선
  • 관리자 기능 UI 개선 및 기존 화면 오류 수정

사용 기술

JavaScriptHTMLCSS

경험

업무용 기기의 안드로이드 버전 및 지원 환경을 함께 고려해서 실제 운영 조건에 맞춰 레이아웃과 코드를 조정하고 개선하였습니다.
